# Project1 - Fullstack Application

This project is a fullstack application with a Next.js frontend, a FastAPI backend, and a database (SQLite/Postgres) interacting with the Gemini API.

## System Architecture

*   **Frontend**: Next.js
*   **Backend**: FastAPI
*   **Database**: SQLite/Postgres
*   **AI/ML**: Gemini API
